# Limitations and scientific integrity

- This is an educational toolkit, not a claim of quantum advantage.
- Ideal statevector results do not represent a particular device's noise or calibration.
- Aer results are simulations; label them as such in any publication or report.
- Hardware execution is not implemented as an automatic default. Add provider integrations separately and keep credentials out of source control.
- Results may vary with Qiskit/Aer versions, seeds, shots, transpiler configuration and platform.
- Grover's example demonstrates circuit construction, not an optimized search implementation for all sizes.
