# Security Policy

## Supported versions

Only the latest release on the `main` branch receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub:
<https://github.com/egkhor/qiskit-learning-lab/security/advisories/new>

Include what you found, how to reproduce it, and the affected version. You can expect an acknowledgement within a few days. This is an educational project maintained by one person, so response times are best-effort.

## Credentials

This project needs no credentials. If you find an API key, token or other secret in the repository or its history, please report it using the link above.
