# Lesson 4 — Quantum teleportation (extension exercise)

Build a three-qubit teleportation circuit: prepare an input state on q0, create a Bell pair on q1/q2, perform the Bell measurement operations, and apply classically conditioned corrections. Extend this lesson with dynamic-circuit support appropriate to your pinned Qiskit version. Explain that teleportation transfers a quantum state using entanglement and classical communication; it does not transmit information faster than light.
